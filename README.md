# Store ON-HTML 🚀

Plataforma y tienda de aplicaciones libre para la distribución de programas de PC (`.exe`) y aplicaciones Android (`.apk`). Integrada con autenticación permanente vía Discord OAuth2 sin comisiones ni restricciones de publicación.

Desarrollada bajo el ecosistema **ON-HTML** por el equipo **stupid dev**.

## 🛠️ Características Principales

- **Publicación Libre:** Sube y comparte ejecutables Windows (`.exe`) y paquetes Android (`.apk`) de forma totalmente gratuita.
- **Autenticación con Discord:** Inicio de sesión rápido y seguro con persistencia local (`localStorage`) que mantiene las URLs limpias.
- **Soporte PWA / Web:** Diseñada para funcionar perfectamente en navegadores y en entornos móviles Android.
- **Licencia Abierta:** Código bajo Licencia MIT para soporte y contribución de la comunidad.

## 🚀 Despliegue en Vercel

1. Clonar el repositorio:
   ```bash
   git clone [https://github.com/tu-usuario/store-on-html.git](https://github.com/tu-usuario/store-on-html.git)

   ```

2. Importar el proyecto en [Vercel](https://vercel.com).
3. Configurar el subdominio personalizado en Vercel apuntando a `store.on-html.duckdns.org`.
